
https://github.com/HenrySpartGlobal/Unity_Stealth_Game: Es un juego de sigilo completo con luces que representan los conos de visión. Es 2d pero sería similar a lo que necesitamos.

https://github.com/liderako/stealth_game3d: Es un repositorio enfocado en mecánicas de sigilo para entornos tridimensionales. Dice 3d aunque no probé.

https://github.com/joscanper/unity_coneofsightfx: Es un sistema diseñado para renderizar el rango de vista en tres dimensiones. Este sí es 3d, para la visión de los npcs puede servir.

https://github.com/marwanzaky/Enemy-Vision: sistema de detección de enemigos usando raycasting. Me pareció otra opción más similar.

Buscar más: https://github.com/topics/stealth-game?o=asc&s=updated

https://github.com/PiRadHex/Unity-Interaction-System-Toolkit (demo: https://piradhex.itch.io/interaction-system-toolkit):  toolkit con varias cosas aunque lo que más me gustó fue la forma de movimiento clickeando.


https://github.com/wassimcodes/AI-patrol-tool-unity: Son herramientas para armar sistemas de patrullaje de los npcs.

https://github.com/FelixBole/quest-system: framework de tareas modular impulsado por un sistema de eventos. Parece muy complejo pero puede ayudar algo.

https://github.com/yusufkerman/Unity-Quest-System: Es un sistema para manejar los objetivos y misiones del jugador, parece más simple.

Buscar más: https://github.com/topics/interaction-system

https://github.com/ashblue/fluid-dialogue: Es una herramienta que incluye un sistema de interfaz por nodos. Sirve para generar diálogos y trae un editor visual con grafos.

https://github.com/marcusaasjensen/dialogue-system: Es otro framework para construir conversaciones mediante ramificaciones visuales. Es otra forma de generar diálogos editando un grafo.
